# AI-Powered Roommate & PG Finder

## Overview

AI-Powered Roommate & PG Finder is a full-stack web application that helps users find compatible roommates and suitable PG accommodations using AI-based personality and lifestyle analysis.

## Features

- User Authentication & Authorization
- AI-Based Roommate Matching
- Compatibility Score Prediction
- Conflict Prediction System
- PG Recommendation Engine
- Room Booking Module
- User Profile Management
- Admin Dashboard

## Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- Node.js
- Express.js
- JWT Authentication
- bcrypt

### Database
- MongoDB
- Mongoose

### Machine Learning
- Python
- Flask
- Scikit-Learn
- Random Forest Regressor


## System Architecture

Frontend (React.js)
        ↓
Backend (Node.js + Express.js)
        ↓
MongoDB Database
        ↓
Flask ML Service
        ↓
Random Forest Compatibility Model
